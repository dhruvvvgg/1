# Photographic revision

All seven page routes (home, the five new pages and the legacy engineering page) now use full-width photographic hero backgrounds with overlaid type. The Home / page breadcrumbs are removed. The homepage keeps its large SRM wordmark as white type over a campus aerial. Supporting photos use full-bleed editorial bands and paired images rather than rounded hero cards. The existing navigation, serif body, gold controls and UB footer remain.

## Discovery and provenance

The files below were downloaded from those sources, inspected, and saved as optimized WebP assets. No AI-generated replacements, geometry changes or upscaling were used. Web display uses proportional cover crops. Credits link to the source page; source attribution is not a claim that search results confer a reuse licence.

## Verification

The source/preview gate checks all local links, fragments, image dimensions, headings and IDs. Browser checks cover all seven routes and their previews at five viewport widths, including hero geometry, image loading, lack of breadcrumbs and horizontal overflow. Phone and desktop screenshots are reviewed; the existing directory and route-guide controls are regression checked.

Verified: 70 page/viewport combinations across source and previews, with no horizontal overflow or runtime/resource errors. All heroes fill the page width and their image fills the hero, with no rounded image frame. Interaction regressions passed for academic search, empty/reset states, admissions routes, recruiter search, native modal Escape and no-JavaScript content.
